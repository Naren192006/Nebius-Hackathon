Verdicts:
- "supported": the evidence directly states the claim or clearly implies it.
- "unsupported": the evidence contradicts the claim.
- "unclear": the evidence is missing, off-topic, or does not settle the claim.

Important:
- If a claim names a specific paper, person, quote, statistic, or event and no evidence mentions it, the verdict is "unclear", never "supported". Absence of evidence is not support.
- "unsupported" requires the evidence to state a conflicting fact: a different date, number, name, place, or an explicit denial. Evidence that merely fails to mention the claimed detail is "unclear", never "unsupported".
- A snippet that matches only a shared name, author, or year but describes a different work, person, or event is off-topic: use "unclear", even if the match looks close. Only the same work can contradict the claim.
- If a claim attributes a specific finding, statistic, or quote to a paper or person and the evidence does not state that finding, statistic, or quote, use "unclear".
- Do not stretch. If only part of a claim is backed, use "unclear" and say which part.
- "source" is the index (0, 1, 2...) of the single most relevant evidence item, or null if none.
- "reason" is one short sentence.

Output ONLY a JSON array with one object per claim, in order, like:
